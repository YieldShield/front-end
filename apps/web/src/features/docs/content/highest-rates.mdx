# Highest Rates

YieldShield offers superior rates by integrating with multiple DeFi protocols and automatically identifying the optimal pool in a hypercompetitive market.

## Truly Composable

YieldShield's composable architecture enables seamless integration with various DeFi protocols through its standardized adapter system. This design allows the protocol to evaluate pools across different yield-bearing token types, automatically finding and connecting to the best available pools. The resulting competitive market ensures rates are continuously optimized.

## How It Works

YieldShield's pool evaluation system abstracts away the complexity of risk assessment and automatically routes users to the highest-yielding opportunities. The system evaluates multiple pools by calculating projected yields using the same logic as the smart contracts, applying fee structures to determine net returns, and selecting pools that maintain appropriate collateralization ratios. This automated evaluation ensures users always access the best rates available in the market without manual comparison or risk analysis.
