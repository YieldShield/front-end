# Code of Conduct

YieldShield aims to keep project spaces useful, focused, and respectful. This
code applies to repository issues, pull requests, discussions, reviews, and any
project-managed community spaces.

## Expected Behavior

- Be respectful and constructive, especially when disagreeing.
- Keep feedback about code, docs, design, and process specific and actionable.
- Assume good intent while still asking for clarity when something is risky or
  confusing.
- Respect maintainer decisions about scope, security handling, and release
  timing.
- Avoid sharing private, sensitive, or security-impacting details in public
  channels.

## Unacceptable Behavior

- Harassment, threats, intimidation, or discriminatory language.
- Personal attacks, sustained disruption, or bad-faith participation.
- Publishing private information without consent.
- Publicly disclosing vulnerabilities before maintainers have completed triage.
- Spam, scams, impersonation, or attempts to manipulate users into unsafe
  transactions.

## Reporting

Report conduct issues to the maintainers through a GitHub issue that describes
the concern without exposing private information. If the issue involves a
security vulnerability, follow `SECURITY.md` instead and do not include details
in a public issue.

Maintainers may remove content, edit or close issues, block accounts, or take
other steps needed to protect the project and its contributors.
